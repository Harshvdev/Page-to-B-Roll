# Fix: Second Export Gets Stuck After First Export Completes

## Root Cause

The bug is a race condition in the offscreen document lifecycle. After the first export completes:

1. `RENDER_COMPLETE` is received by the service worker (`service-worker.js:335`)
2. Chrome download is initiated (`service-worker.js:347`)
3. A `chrome.downloads.onChanged` listener waits for the download to finish
4. When the download completes, a **1-second `setTimeout`** then calls `closeOffscreenDocument()` (`service-worker.js:359-361`)

If the user clicks Export again **before that 1-second timer fires** (or while the download is still in progress):

1. `onExportClick()` in `sidepanel.js:244` starts a new export
2. The service worker calls `ensureOffscreenDocument()` (`service-worker.js:295`), which closes the old offscreen and creates a **new** one
3. The new offscreen begins rendering
4. Meanwhile, the **old** download's `setTimeout` fires → `closeOffscreenDocument()` → **closes the NEW offscreen document**
5. The new export's offscreen is gone, so `RENDER_COMPLETE` or `RENDER_ERROR` is never sent back → side panel UI stays stuck on "Cancel Export" forever

## Fix

Add an `exportGeneration` counter in the service worker. Each new export increments it. The `RENDER_COMPLETE` and `RENDER_ERROR` handlers capture the generation when they fire, then check if it's still current before forwarding to the side panel or closing the offscreen.

### File: `background/service-worker.js`

**1. Add generation counter** (near `let activeTabId = null;` at line 5):
```js
let exportGeneration = 0;
```

**2. Increment generation at the start of `RENDER_VIDEO` handler** (line ~273, before the async IIFE):
```js
if (type === MSG.RENDER_VIDEO) {
    exportGeneration++;
    // ... rest of existing code
```

**3. Guard `RENDER_COMPLETE` handler** (line ~335) — capture generation, check before side-panel forward and offscreen close:
```js
if (type === MSG.RENDER_COMPLETE) {
    const gen = exportGeneration;
    (async () => {
      if (gen !== exportGeneration) return;
      // ... existing code: remove storage, incrementExportCount, forwardToSidePanel, download ...
      // In the download callback, only closeOffscreenDocument if still current:
      setTimeout(() => {
        if (gen === exportGeneration) closeOffscreenDocument();
      }, 1000);
    })();
    return false;
  }
```

**4. Guard `RENDER_ERROR` handler** (line ~371) — same pattern:
```js
if (type === MSG.RENDER_ERROR) {
    const gen = exportGeneration;
    (async () => {
      if (gen !== exportGeneration) return;
      // ... existing code: remove storage, forwardToSidePanel, closeOffscreenDocument
    })();
    return false;
  }
```
