# Fix Export Stuck on "Preparing renderer..." + Cancel Not Working

## Root Cause

The new code (master branch) changed the service worker's message routing for `RENDER_PROGRESS`, `RENDER_COMPLETE`, and `RENDER_ERROR` — it **stores them in `chrome.storage.local` but no longer forwards them to the sidepanel**. The sidepanel relies on `chrome.runtime.onMessage` for live progress/completion/error updates, so it never receives them and gets stuck.

### Specific Breakages

**1. RENDER_PROGRESS not forwarded to sidepanel (causes "stuck on Preparing renderer...")**

Old code (`service-worker.js`):
```js
if (type === MSG.RENDER_PROGRESS) {
    forwardToSidePanel(message);  // ✓ Sidepanel gets live updates
    return false;
}
```

New code:
```js
if (type === MSG.RENDER_PROGRESS) {
    (async () => {
      await chrome.storage.local.set({...});  // ✗ Only stores, never forwards
    })();
    return false;
}
```

The sidepanel only reads from storage on `DOMContentLoaded` (once at startup). During rendering, it depends on live messages. Since the offscreen sends `RENDER_PROGRESS` → service worker swallows it → sidepanel never sees it.

**2. RENDER_COMPLETE not forwarded to sidepanel (causes stuck UI after export)**

Old code:
```js
if (type === MSG.RENDER_COMPLETE) {
    (async () => {
      await incrementExportCount();
      await closeOffscreenDocument();
      forwardToSidePanel(message);  // ✓ Sidepanel knows export finished
    })();
}
```

New code:
```js
if (type === MSG.RENDER_COMPLETE) {
    (async () => {
      // Handles download in service worker
      // ✗ Never calls forwardToSidePanel
    })();
}
```

**3. RENDER_ERROR not forwarded to sidepanel (causes stuck UI on error)**

New code never forwards `RENDER_ERROR` to the sidepanel — the UI stays in "exporting" state even when the render fails.

**4. CANCEL_RENDER not handled in service worker**

The sidepanel sends `CANCEL_RENDER` but the service worker has no handler — message is silently dropped.

## Plan

### File: `background/service-worker.js`

**Change 1**: `RENDER_PROGRESS` handler — forward to sidepanel AND store in chrome.storage:
```js
if (type === MSG.RENDER_PROGRESS) {
    forwardToSidePanel(message);  // ADD THIS BACK
    (async () => {
      await chrome.storage.local.set({
        [STORAGE.EXPORT_PROGRESS]: message.payload.percent,
        [STORAGE.EXPORT_STATUS]: message.payload.status,
      }).catch(() => {});
    })();
    return false;
}
```

**Change 2**: `RENDER_COMPLETE` handler — forward to sidepanel AND handle download:
```js
if (type === MSG.RENDER_COMPLETE) {
    (async () => {
      await chrome.storage.local.remove([...]).catch(() => {});
      await incrementExportCount();
      forwardToSidePanel(message);  // ADD THIS BACK
      const { blobUrl, filename } = message.payload;
      chrome.downloads.download({ url: blobUrl, filename: filename }, ...);
    })();
    return false;
}
```

**Change 3**: `RENDER_ERROR` handler — forward to sidepanel:
```js
if (type === MSG.RENDER_ERROR) {
    (async () => {
      await chrome.storage.local.remove([...]).catch(() => {});
      forwardToSidePanel(message);  // ADD THIS BACK
      await closeOffscreenDocument();
    })();
    return false;
}
```

**Change 4**: Add `CANCEL_RENDER` handler:
```js
if (type === 'CANCEL_RENDER') {
    console.log('[Broll SW] CANCEL_RENDER received, forwarding to offscreen');
    (async () => {
      try {
        await chrome.runtime.sendMessage({ type: 'CANCEL_RENDER' });
      } catch (e) {}
      await chrome.storage.local.remove([
        STORAGE.EXPORT_ACTIVE,
        STORAGE.EXPORT_PROGRESS,
        STORAGE.EXPORT_STATUS
      ]).catch(() => {});
    })();
    return false;
}
```

### File: `offscreen/offscreen.js`

**Change 5**: Add `isCancelled` check after stitch phase:
```js
const imageBitmap = await stitchStrips(strips, pageWidth, pageHeight, devicePixelRatio || 1);
if (isCancelled) {
    throw new Error('Render cancelled by user');
}
```

### No changes needed to:
- `offscreen/offscreen.html` (cache-busting already present from prior edit, harmless)
- `lib/canvas-compositor.js` (cachedDims optimization is fine)
- `sidepanel/sidepanel.js` (already handles RENDER_PROGRESS, RENDER_COMPLETE, RENDER_ERROR correctly)
- `lib/export.js` (GIF/PNG additions are fine)
